A collection of Python projects with runnable code and project documentation.

## Run Number Guesser

Requires Python 3.10 or newer. No runtime dependencies.

```bash
cd 01-number-guesser-game
python3 main.py
```

See the [project README](01-number-guesser-game/README.md) for installation, gameplay, architecture, and tests.
